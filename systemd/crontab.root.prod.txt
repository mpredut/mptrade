# crontab.root.prod — snapshot of the ROOT crontab on the PROD machine (trading).
# Reproducible: after a disaster, restore with:  crontab -u root systemd/crontab.root.prod.txt
# (or automatically, through systemd/install_prod.sh)
# Synced with PROD: 2026-09-19.
#
# NOTE: pia_selfheal.sh has been removed from this crontab.
# pia.service (systemd, Restart=always) is the sole automated PIA recovery mechanism.
# Running pia_selfheal.sh from cron creates a competing restarter that fights pia.service
# over piactl calls. Use ./pia_selfheal.sh --check or --force for manual intervention only.

SHELL=/bin/bash
TRADING_ROOT=@TRADING_ROOT@

# Auto-deploy (SHADOW by default -- observe only; set AUTODEPLOY_MODE=on in
# autodeploy.local.conf to apply). Pulls a moved origin/main and restarts the fleet; never
# reboots. See manage_gitautodeploy.sh.
*/10 * * * * cd $TRADING_ROOT && ./orchestratorOS/admin/manage_gitautodeploy.sh >> logs/autodeploy.log 2>&1

# PIA Network guard with exponential backoff (now safe for cron)
*/5 * * * * cd $TRADING_ROOT && ./orchestratorOS/livecheck/vpn_watchdog.sh >> logs/vpn_watchdog.log 2>&1

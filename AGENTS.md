# Repository language policy
- **Strict English:** Everything created or modified in this repository must be exclusively in English.
- **Auto-Push:** Always push completed and verified commits to the upstream branch automatically.

# Core Architectural Tenets
- **Unification, Compaction, and Centralization:** All engineering designs must prioritize unifying split or fragmented guard/execution steps, compacting redundant operations, and centralizing domain rules into coherent, linear choke points without redundant backtracking.
- **Single Source of Truth (SSOT):** Every piece of domain knowledge, state, configuration value, or operational rule must have a single authoritative representation and resolution path, eliminating duplicate, fragmented, or conflicting definitions across the codebase.

# Core Tenets
- **Single Source of Truth (SSOT) & Reuse-First:** Consolidate logic into linear choke points; generalize and reuse existing primitives before creating new helpers or classes.
- **Zero Static Fallbacks (Fail-Fast Init):** Never hardcode magic numbers, thresholds, intervals, URLs, or symbol lists in Python, and never provide fallback defaults or synonym guessing for static config keys. Validate required settings at load/init (`raise ValueError`/`KeyError`). Reserve fallbacks strictly for runtime operational resilience (WS->REST, missing live trend, fail-closed guards).
- **Mathematical Dependency Chains:** Express derived intervals, TTLs, and staleness bounds as explicit formulas of the primary anchor variable (e.g., `resolve_crypto_executor_interval_sec()`, `resolve_derived_telemetry_intervals()`) rather than pre-calculated static numbers.
- **Symmetry & Naming Grammar:** Maintain strict `BUY`/`SELL` and cross-venue symmetry via shared primitives (`opposite_side()`, `profit_diff_pct()`, `select_extreme_reference()`). Follow uniform naming (`Cache<Qualifier><Domain>Manager`, `cache_<qualifier>_<domain>.json[l]`, `get_<qualifier>_<domain>_manager()`).
- **Holistic Choke-Point Fixes:** Fix classes of bugs at the shared boundary (transport, gateway, state layer) rather than adding per-caller `if/else` patches.

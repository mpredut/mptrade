## 2. Reguli de Retenție a Istoriei și Compactare Automată (`/compact`)

1. **Un singur Thread Permanent per Topic (`conversation_id` fix):**
   - Fiecare din cele 6 topicuri din [`TOPIC_SPECS`](file:///home/predut/mptrade/orchestratorOS/agy/topics.py#L51-L62) își păstrează același `conversation_id` pe toată durata de viață a sistemului.
   - Toate `conversation_id`-urile din [`cachedb/llm_topic_threads.json`](file:///home/predut/mptrade/cachedb/llm_topic_threads.json) sunt protejate automat în [`get_active_topic_cids()`](file:///home/predut/mptrade/orchestratorOS/agy/topics.py#L99-L106) și nu sunt niciodată șterse de jobul de curățenie [`orchestratorOS/admin/prune_llm_threads.py`](file:///home/predut/mptrade/orchestratorOS/admin/prune_llm_threads.py).
2. **Când se trimite Compactarea Automată (`/compact`):**
   - Înaintea fiecărui ciclu, [`prepare_topic_session()`](file:///home/predut/mptrade/orchestratorOS/agy/topics.py#L178-L218) citește numărul curent de pași (`step_count`) din baza SQLite `conversation_summaries.db` și îl compară cu pasul la care s-a făcut ultima compactare (`compacted_at_step`).
   - Când `step_count - compacted_at_step >= LLM_TOPIC_COMPACT_STEPS` (`18` în [`config.env`](file:///home/predut/mptrade/config.env#L399)), după executarea promptului JSON tura trimite automat `/compact` pe același `conversation_id` ([`intelligence/sentiment/gemini_client.py`](file:///home/predut/mptrade/intelligence/sentiment/gemini_client.py)), rezumând în-loc toată istoria conversației fără a schimba ID-ul thread-ului.
   - Întrucât o tură standard adaugă **~3–3.5 pași de traiectorie** (`USER_INPUT` + `PLANNER_RESPONSE`), compactarea automată se declanșează o dată la **~5–6 cicluri (turns)** ale acelui topic.
3. **Sincronizarea Bidirecțională cu Web UI (`mptrade`):**
   - Înainte de fiecare tură, [`sync_topic_thread_from_ui()`](file:///home/predut/mptrade/orchestratorOS/agy/ui_mirror.py#L38-L125) verifică dacă utilizatorul a scris o instrucțiune în chat-ul din Web UI și sincronizează baza `.db` mai nouă din UI în store-ul `agy-bot`.
   - După fiecare tură, [`mirror_topic_thread_to_ui()`](file:///home/predut/mptrade/orchestratorOS/agy/ui_mirror.py#L127-L195) oglindește răspunsul și titlul canonic din `TOPIC_SPECS` înapoi în store-ul Web UI.

## 2. History Retention and Automated Compaction (`/compact`) Rules

1. **Single Permanent Thread per Topic (Fixed `conversation_id`):**
   - Each of the 7 topics in [`TOPIC_SPECS`](file:///home/predut/mptrade/orchestratorOS/agy/topics.py#L89-L130) retains the same `conversation_id` across the lifetime of the system.
   - All `conversation_id`s in [`cachedb/system/llm_topic_threads.json`](file:///home/predut/mptrade/cachedb/system/llm_topic_threads.json) are protected in [`get_active_topic_cids()`](file:///home/predut/mptrade/orchestratorOS/agy/topics.py#L99-L106) and are never deleted by [`orchestratorOS/admin/prune_llm_threads.py`](file:///home/predut/mptrade/orchestratorOS/admin/prune_llm_threads.py).
2. **When Automated Compaction (`/compact`) Is Triggered:**
   - Before each cycle, [`prepare_topic_session()`](file:///home/predut/mptrade/orchestratorOS/agy/topics.py#L178-L218) reads the current trajectory step count (`step_count`) from `conversation_summaries.db` and compares it against the last compacted step (`compacted_at_step`).
   - When `step_count - compacted_at_step >= LLM_TOPIC_COMPACT_STEPS` (`18` in [`config.env`](file:///home/predut/mptrade/config.env#L399)), after executing the JSON prompt the turn automatically sends `/compact` on the same `conversation_id` ([`intelligence/sentiment/gemini_client.py`](file:///home/predut/mptrade/intelligence/sentiment/gemini_client.py)), summarizing the conversation history in-place without changing the thread ID.
   - Because a standard turn appends **~3-3.5 trajectory steps** (`USER_INPUT` + `PLANNER_RESPONSE`), automated compaction fires once every **~5-6 cycles (turns)** of that topic.
3. **Bidirectional Synchronization with Web UI (`mptrade`):**
   - Before each turn, [`sync_topic_thread_from_ui()`](file:///home/predut/mptrade/orchestratorOS/agy/ui_mirror.py#L38-L125) checks whether the user posted an interactive instruction in the Web UI chat and syncs the newer `.db` from the UI store into `agy-bot`.
   - After each turn, [`mirror_topic_thread_to_ui()`](file:///home/predut/mptrade/orchestratorOS/agy/ui_mirror.py#L127-L195) mirrors the response and canonical title from `TOPIC_SPECS` back into the Web UI store.
